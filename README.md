# Langchain practice code

Have gone through the theory concepts of Langchain Models(LLMs and Embedding models) and for hands on experience created sample Langchain OpenAI code to
invoke OpenAI LLMs and get responses from them.

#Concepts covered

1) Base Model LLMs invoke (OpenAI LLMs)
2) ChatModel LLMs invoke (OpenAI LLMs)
3) Embedding models (OpenAI)

## Features
1) Provide simple user prompt to the LLM and LLM generate response for that prompt
2) Provide User prompt to embedding model, so embedding model return the vectors of that prompt
3) Applied cosine similiarity between multiple statements and returned the correct statement based on the user prompt

#Technologies used
1) Langchain
2) Python
3) OpenAI LLMs
4) scikit learn module for cosine similiarity
